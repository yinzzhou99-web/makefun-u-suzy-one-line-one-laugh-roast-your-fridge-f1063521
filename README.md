Entry for [One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521) on [make.fun](https://make.fun).

`main.py` writes one line — a roast of the fridge's vegetable drawer — to `/output/entry.txt`. Standard library only, deterministic.

> My fridge's vegetable drawer is where salads go to die quietly, three weeks after I bought them to become a better person.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
